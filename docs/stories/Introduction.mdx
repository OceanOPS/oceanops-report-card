# Global Ocean Observing System Status Report 2025 - Component Library

Welcome to the **Global Ocean Observing System Status Report 2025** component documentation. This Storybook showcases all UI components used in the GOOS Status Report.

## 🌊 About This Project

The Global Ocean Observing System Status Report 2025 is a multilingual web application presenting the status of global ocean observing networks. Built with modern web technologies and following the GOOS design system.

## 📚 What You'll Find Here

### **Brand**
Official GOOS logos and partner branding elements used throughout the application.

### **Foundation**
Design system fundamentals:
- **Colors**: GOOS color palette with 5 main colors (Blue, Cyan, Orange, Green, Gray)
- **Typography**: Roboto and Roboto Condensed typefaces

### **Components**
Reusable UI components organized by purpose:
- **Data**: Tables, cards, and statistics displays
- **Media**: Images, galleries, and video players
- **Interactive**: Buttons, modals, and navigation
- **Content**: Quote blocks, content boxes

### **Layout**
Large structural components:
- Cover module, content sections, carousels, delivery areas

## 🎨 GOOS Design System

The project uses a comprehensive design system with:
- **5 color palettes** × 9 shades each (45 total colors)
- **Responsive design** (mobile-first approach)
- **3 languages**: English, Spanish, French
- **Accessibility** built-in

## 🛠️ Tech Stack

- **React 18** + **TypeScript 5**
- **Tailwind CSS 3** for styling
- **react-i18next** for internationalization
- **GSAP** for animations
- **Embla Carousel** for carousels

## 📖 How to Use Components

All components follow these patterns:

### Translation Keys
Components accept translation keys (not translated text):
```tsx
<Button
  variant="link"
  label="View Network"  // Direct text in Storybook
  // In real app: label={t('networks.viewNetwork')}
/>
```

### GOOS Colors
Use Tailwind classes from the GOOS palette:
```tsx
bgColor="bg-goos-blue-700"
textColor="text-white"
```

### Responsive Props
Many components have responsive behavior built-in using Tailwind breakpoints.
