# Figma Designs

This section displays the original Figma designs for each component. You can view, interact, and compare designs directly from Storybook.

## How to Use This Section

1. **View the design**: Figma designs are embedded below
2. **Interact**: You can zoom, navigate through frames
3. **Open in Figma**: Click "Open in Figma" to view the full file
4. **Compare**: Use this page alongside the components to compare design vs implementation
