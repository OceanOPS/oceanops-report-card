## Usage

Import icons in your React components by referencing the path from the public folder:

```jsx
// Delivery area icon
<img src="/icons/climate.png" alt="Climate" />

// Physics icon
<img src="/icons/physics/Surface-temperature.png" alt="Surface Temperature" />

// Network logo
<img src="/icons/network/argo.svg" alt="Argo Network" />
```

### With i18n Alt Text

For accessibility, use translation keys for alt text:

```jsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <img
      src="/icons/climate.png"
      alt={t('icons.climate')}
    />
  );
}
```

### Icon Sizing

Common sizing patterns used throughout the app:

- **Small (16-24px)**: Inline icons, tooltips
- **Medium (40-60px)**: Card icons, grid displays
- **Large (80-120px)**: Hero sections, feature highlights

```jsx
// Small
<img src="/icons/climate.png" className="w-6 h-6" />

// Medium
<img src="/icons/climate.png" className="w-12 h-12" />

// Large
<img src="/icons/climate.png" className="w-20 h-20" />
```
