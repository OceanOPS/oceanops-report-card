# Spacing System

The OceanOPS Report Card uses a consistent spacing system based on Tailwind CSS defaults and the **Spacer** component.

## Spacer Component

The `Spacer` component provides vertical spacing between sections with predefined sizes.

### Sizes Available

| Size | Tailwind Class | Height | Use Case |
|------|---------------|--------|----------|
| **xs** | `h-4` | 16px | Minimal spacing within components |
| **sm** | `h-8` | 32px | Between related elements |
| **md** | `h-16` | 64px | Between subsections |
| **lg** | `h-24` | 96px | Between major sections |
| **xl** | `h-32` | 128px | Between large content blocks |

### Usage

```tsx
import Spacer from '@/components/Spacer'

<ContentModule>
  {/* Content */}
</ContentModule>

<Spacer size="lg" />

<ContentModule>
  {/* More content */}
</ContentModule>
```

## Component Spacing Patterns

### ContentModule Gaps

ContentModule uses consistent internal spacing:
- **Title to content**: `gap-4` (16px) on mobile, `gap-8` (32px) on desktop
- **Paragraph spacing**: `space-y-4` (16px between elements)
- **Section padding**: `px-4` (16px) on mobile, `px-8` (32px) on desktop

### Grid Gaps

- **ImageGrid**: `gap-4` (16px)
- **StatsGrid**: `gap-4` (16px)
- **DataCardGrid**: `gap-6` (24px)
- **InsightGrid**: `gap-6` (24px)

### Responsive Spacing

Many components use responsive spacing:

```tsx
className="p-4 md:p-6 lg:p-8"
// Mobile: 16px
// Tablet: 24px
// Desktop: 32px
```

## Best Practices

### ✅ Do
- Use `Spacer` component for vertical spacing between major sections
- Use Tailwind spacing utilities for component internal spacing
- Use consistent values from the spacing scale
- Consider responsive spacing for better mobile experience

### ❌ Don't
- Avoid custom pixel values (use Tailwind scale instead)
- Don't mix different spacing systems
- Avoid excessive nesting of spacing utilities
